# LogiOn Android

Kotlin + Jetpack Compose로 개발했으며,  
FastAPI 백엔드와 연동하여 배송 정보 조회, 배송 완료,  
상품 확인, 바코드 조회, 이상 보고 기능을 제공합니다.

## 주요 기능

- 오늘 배송 정보 및 진행률 표시
- 다음 배송지 안내
- 배송목록 전체 / 진행 중 / 완료 필터
- 배송지 상세 조회
- 상품 구역 체크 및 서버 저장
- 배송 완료 / 완료 취소
- 매장 전화 연결
- 지도 앱 연결
- 수기 바코드 상품 조회
- 이상 보고
  - 파손, 수량 부족, 오배송, 온도이상
- 기본 예외 처리
- API 중복 요청 방지

## 카메라 바코드 스캔

CameraX와 ML Kit Barcode Scanning을 이용해 구현했습니다.

구현된 기능:

- 카메라 권한 처리
- 카메라 미리보기
- 바코드 자동 인식
- 인식한 바코드로 상품 조회
- 다시 스캔
- 카메라 실행 실패 처리

> 카메라 기능은 코드 구현 완료 상태이며  
> 실제 Android 기기에서의 바코드 인식 테스트는 진행 예정입니다.

## 백엔드 연결

Retrofit을 사용해 FastAPI 서버와 연동했습니다.

- 에뮬레이터 테스트 완료
- 실제 기기 테스트 예정
