# LogiOn 납품 음성 명령 데이터셋

편의점 납품기사가 음성 비서에게 하는 말 **2,754문장**과 그 정답 라벨입니다.
같은 2,754문장을 두 모델용으로 나눠 놓은 것이라, 두 CSV는 `id`·`text`·`split`이 완전히 같고 **정답 열만 다릅니다.**

| 파일 | 용도 | 정답 열 |
|---|---|---|
| `intent_dataset.csv` | 의도분류 모델 (klue/roberta-small) | `label` : 6개 기능 중 하나 |
| `fc_dataset.csv` | Function Calling 모델 (Qwen2.5-1.5B + LoRA) | `target` : 함수와 값을 담은 JSON |
| `gemini_prompt.txt` | 제미나이로 문장을 만들 때 쓴 프롬프트 | |
| `gemini_raw.jsonl` | 제미나이가 만든 원본 236줄 (검증 후 234줄 사용) | |
| `calibration_utterances.json` | 양자화(W8A8) 보정용 문장 450건 | |

## 열 설명 (두 CSV 공통)

| 열 | 내용 |
|---|---|
| `id` | 문장 번호 (`u00000`~). 두 CSV에서 같은 문장은 같은 id |
| `text` | 기사가 말한 문장 |
| `split` | `train` 1,940 / `val` 383 / `test` 431 |
| `source` | `template` 2,520 (말 틀로 생성) / `gemini` 234 (제미나이 생성) |
| `ambiguity` | `clear` 2,206 (바로 확정) / `ask` 170 (되물어야 함) / `hard` 378 (다른 기능과 헷갈림) |

- `intent_dataset.csv`의 `label`: `next_stop` · `stop_items` · `complete` · `report_issue` · `scan` · `other` (기능마다 약 460건).
- `fc_dataset.csv`의 `target` 예: `{"fn":"report_issue","store":"개포점","item":"캔커피","issue":"오배송"}`
  - 문장에서 **말한 값만** 적고, 말하지 않은 값은 키를 쓰지 않습니다.
  - 키: `store`(점포) · `item`(품목) · `receiver`(인수자) · `issue`(파손·수량부족·오배송·온도이상) · `qty`(정수) · `unit`(개·박스·판·봉지)

## 분할 방식

기능마다 말 틀 32개를 만들고, **틀 단위로** train/val/test를 나눴습니다. test 문장은 학습에 없던 틀에서 나옵니다.
제미나이 문장 중 30%는 test에만 넣었습니다.

틀 배정은 `template_split_v1.json` 에 고정해 두고 그대로 씁니다. v1 모델과 v2 모델을 **같은 새 test** 로 공정하게 비교하려면, v1 이 학습에서 본 틀이 새 test 에 들어가지 않아야 하기 때문입니다. (실제로 새 test 431문장 중 v1 의 train·val 과 겹친 문장은 0건입니다.)

## 수량 라벨 규칙 (v2에서 고침)

v1 데이터에는 **말에는 수량이 있는데 정답 JSON 에 `qty` 가 없는 report_issue 문장이 27건** 있었습니다. 이것이 v1 오답 57건 중 11건의 원인이었습니다. v2에서 아래 규칙으로 고쳐 **0건**이 되었습니다.

| 말한 방식 | 예 | 정답 |
| --- | --- | --- |
| 수와 단위를 함께 | "우유 두 박스 터졌어" | `qty: 2, unit: "박스"` |
| 틀의 고정 문구에 단위가 있음 | "우유 **박스 하나** 터졌어" | `qty: 1, unit: "박스"` |
| 단위 없이 수만 | "우유 **둘** 터졌어" | `qty: 2` (unit 없음) |
| 문제 표현에 수량이 들어있음 | "**하나 빠졌어**" | `qty: 1` (unit 없음) |
| 수량을 말하지 않음 | "우유 터졌어" | `qty`·`unit` 없음 |

- 말하지 않은 값은 절대 쓰지 않는다는 원칙을 그대로 따릅니다.
- `unit` 은 개·박스·판·봉지 중 하나로 맞춥니다.
- 제미나이 데이터도 같은 기준으로 검사해 2건 보정했습니다 (말하지 않은 `unit` 제거).
- v1 때 쓴 데이터는 `v1/` 에 그대로 보존돼 있습니다.

> 참고: `{item} 박스 하나 {issue}` 틀은 고정 배정에서 **test 에만** 들어가 있어(train 0건 / test 17건), 재학습한 v2 모델이 이 표현을 학습에서 보지 못했습니다. 그 영향은 `docs/midterm_ai_summary.md` 의 "원인 A" 에 적혀 있습니다.

## 주의

- 문장은 생성 데이터 중심이며 실제 기사 발화는 아닙니다. 점포·품목 이름은 가상 목록입니다.
- 텍스트 데이터라 음성(STT) 오인식은 반영되어 있지 않습니다.
